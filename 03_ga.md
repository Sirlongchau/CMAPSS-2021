# 03 — ga.py (optimizer)

Purpose: a generic real-coded genetic optimizer. It is deliberately kept ignorant
of the tree so that "fit a branch" and "fit the full tree" are the same call.

## Decisions

**Model-agnostic by design.** `optimize(loss, lo, hi, seeds=...)` sees only a
bounded real vector and a scalar loss. The core builds the loss and bounds; the GA
never learns whether the vector is one leaf or the whole tree. This is what lets
the curriculum reuse one optimizer for every stage with no special-casing.

**Warm start = seeded initial population, nothing more.** `seeds` injects known
genomes into gen 0 (clipped to bounds; padded if shorter, so a branch genome can
seed a larger full-tree slot). Combined with elitism this guarantees the seed's
quality is never lost, but the seeded genes evolve freely thereafter. That matches
the agreed contract: warm start is a compute saver for the full-tree fit, not a
constraint on it.

**Operators chosen for reproducibility, not cleverness.** Tournament selection,
BLX-α crossover, range-scaled Gaussian mutation, elitism. The landscape here is
mild (fixed MFs, smooth loss); the payoff is a stable, seedable optimizer, so a
fixed `seed` reproduces a run exactly.

## Interface

`optimize(loss, lo, hi, *, gens, pop, seed, seeds, elite, tourn, alpha, p_mut,
mut_scale, patience, verbose) -> (best_genome, best_loss, history)`.

## Test evidence

`python ga.py`:
- cold start on a smooth 8-D bowl converges to loss < 1e-2 at x ≈ 0.3;
- warm start seeded at the optimum shows gen-0 best = 0 (elitism preserves it) and
  final loss ≤ 1e-9;
- a short seed (length 3 into an 8-D genome) is padded and runs without error —
  the branch-seeds-full-tree path.
